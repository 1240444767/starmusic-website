# 界面预览截图

这里是官网「界面预览」与首屏手机里显示的实机截图。**文件名固定**，换成你自己的截图时保持同名即可，不需要改任何代码。

| 文件名         | 显示位置     | 内容                                   |
| -------------- | ------------ | -------------------------------------- |
| `home.jpg`     | 首屏 + 预览  | 首页（随心榜单 / 每日推荐 / 新歌速递） |
| `player.jpg`   | 界面预览     | 全屏播放器（封面取色 + 歌词）          |
| `search.jpg`   | 界面预览     | 搜索页（猜你想搜 / 四平台结果）        |
| `playlist.jpg` | 界面预览     | 歌单页（标签歌单或歌单详情）           |

## 规格

- **尺寸**：宽 600px 左右即可（手机外框最大显示宽度 268px，600px 已经覆盖 2 倍以上的高清屏）。
- **比例**：竖屏，接近 9:19.5（全面屏）；组件按 `object-fit: cover` 顶部对齐裁切。
- **体积**：单张 150 KB 以内最好（当前四张合计约 480 KB，都是 JPEG q88）。

## 扩展名规则

组件先找 `<文件名>.jpg`，找不到再退回 `<文件名>.png`，两个都没有才显示占位提示。
所以：

- 想省流量：放 `.jpg`（推荐）。
- 想保细节：放 `.png`，把 `.jpg` 删掉即可，无需改代码。

想加更多截图，编辑 `src/app/site-content.ts` 里的 `SHOTS` 数组，加一条 `{ file, label, desc }`（`file` 不带扩展名）。
