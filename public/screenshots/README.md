# 界面预览截图

把 App 的截图按下面的文件名放进这个目录，官网的「界面预览」与首页手机会**自动显示**，不需要改任何代码。
如果文件不存在，页面会显示一个占位提示（写着应该放哪个文件）。

| 文件名         | 显示位置     | 建议内容                                   |
| -------------- | ------------ | ------------------------------------------ |
| `home.png`     | 首页 · 首屏  | 首页（随心榜单 / 每日推荐 / 新歌速递）     |
| `player.png`   | 界面预览     | 全屏播放器（封面取色 + 歌词）              |
| `search.png`   | 界面预览     | 搜索页（猜你想搜 / 四平台结果）            |
| `playlist.png` | 界面预览     | 歌单页（标签歌单或歌单详情）               |

要求：

- 竖屏截图，比例接近 9:19.5（全面屏）最好看；组件用 `object-fit: cover` 裁切，顶部对齐。
- PNG 或 WebP 都行，单张控制在 500 KB 以内（页面会懒加载）。
- 换图之后重新构建或直接刷新页面即可看到。

想加更多截图，编辑 `src/app/site-content.ts` 里的 `SHOTS` 数组，加一条 `{ file, label, desc }` 即可。
